Stage 1:
 Core Mechanics & Initial SetupBuilt the initial project entirely within a single index.html file combining HTML, Tailwind CSS via CDN, and vanilla JavaScript.  Established the core cursor-reactive fleeing creature with a state machine (idle, fleeing, panic, hesitate, fakeout, exhausted) driven by distance-based lerp movement.  Implemented an energy bar (0-100) that drains during movement and regenerates during idleness, triggering a 7-second life-or-death countdown and pleading dialogue when exhausted.  Created dual outcome paths with state-switching to either a Heaven screen (if survived) or a Hell screen (if clicked while exhausted). 

Stage 2: 
 Outcome Screens, Apology Mini-Game & Near-Miss FeedbackAdded the Heaven screen featuring randomized titles, karma ledgers, respect score bars, and sincere compliments.  Integrated the Hell screen trial featuring a devil-judge ("Chaathan presiding") requiring a written apology input.  Implemented a local heuristic apology evaluation algorithm analyzing word count, caps ratio, insincere phrases, and sincerity keywords to accept or reject the apology in a loop.  Added floating "Nice try!" / "Too slow!" near-miss toast notifications when clicking the creature outside of its exhausted state. 
 
 Stage 3: 
  Creature Collection System & Economy OverhaulReplaced the old SVG blob with 20 unique creatures rendered via colored glow circles and character emojis.  Assigned distinct idle animation classes (breathing, bob, sway, wiggle, pulse) across the creature roster.  Introduced an unlock economy where players accumulate unlock points by surviving rounds and spend 80 points to randomly unlock new creatures from the remaining pool.  Added session-persistent collection state and a "Creature Collector" gold achievement banner upon unlocking all 20 options. 

Stage 4:
  Dark Academia / Gothic UI/UX Overhaul & Sound Design (Final Stage)Redesigned the interface with deep obsidian/charcoal tones, frosted glass containers (backdrop-blur-md), glowing amber/gold borders, and custom drop shadows.  Updated thematic elements to fit a moody gothic aesthetic, including a glowing badge frame for the judge and the "Test your morals?" restart button.  Programmed procedural Web Audio UI click blips, a continuous low horror drone in Hell, and a soft ambient piano/arpeggio loop in Heaven.  Embedded an uploaded horror scream sound effect as a base64 Data URI inside the single HTML file, syncing it with capture events alongside a global mute toggle
